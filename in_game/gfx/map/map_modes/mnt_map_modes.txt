### MEIOU and Taxes - Centers of Importance #####
#################################################
#
# One map mode for the four center categories (trade / production / culture /
# education) and their four tiers (local / regional / continental / world),
# replacing the four per-category modes.
#
# Colours follow the dynamic demand map mode: the hue says which category the
# center belongs to, the brightness says how high it ranks, so
#
#     trade      dull bronze -> vivid gold
#     production dull brick  -> vivid red
#     culture    dull plum   -> vivid violet
#     education  dull slate  -> vivid cyan
#
# A location can hold one center per category, so:
#   map_color           -> its highest center (hue = category, brightness = tier)
#   secondary_map_color -> the next center, drawn as stripes
# The tooltip lists every category, its tier, score, factors and effects.
#
# No centers anywhere? The location keeps the default map colour.

				OR = {
					has_location_modifier = mnt_center_trade_world
