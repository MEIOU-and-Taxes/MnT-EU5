# Food per 1k pops per month. Provisions is the staple every class buys to survive,
# nearly flat across classes. Wealthier classes also buy luxury food goods, which
# carry no food. Provisions plus luxury is the class's farming-rework food demand;
# laborers run 0.1 over because their staple is above 1.0. Peasants and slaves are
# outside the food pool entirely, employed or not: they work their own plots at
# home, so food consumption modifiers can never conjure food from the peasantry.
#
#   class     provisions  luxury  total
#   slaves       0         0       0 (feed themselves off the books)
#   peasants     0         0       0 (feed themselves off the books)
#   laborers     1.1       0       1.1
#   soldiers     1.25      0.75    2.0
#   clergy       1.75      0.25    2.0
#   burghers     1.5       1.5     3.0
#   nobles       2.0       3.0     5.0
#
# pop_food_consumption is the total column. Luxury lives on the goods in 03_food.txt.
# The monthly provisions demand in MnT_provisions.txt uses the same column
# and must change with it.
