# [all RGO buildings] sets defaults. A named section like [RGO_building_lumber] overrides what it
# sets; None drops a setting. Each location gets the RGO for its raw material; secondary RGOs are
# levelled the same way but without ideal_rgo_multiplier. fixed_level bypasses the normal
# base+multiplier calculation.
# Values: yes/no, number (25 = 25%), None, list [ "SWE" ], or map { "flatland": 1, "hills": 0.5 }.
# A map only needs what it changes; unlisted names count as 1. Multipliers compound.
